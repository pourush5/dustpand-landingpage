# DustPan — Official Landing Page & Web Showcase

Official high-performance, modern landing page for **DustPan**: a privacy-first, conservative disk triage and space recovery desktop utility engineered natively for Windows 10 & 11 (x64).

## 🚀 Overview

DustPan replaces destructive, blind "cleaners" with non-destructive assisted triage:
- **Zero Surprise Deletions:** Read-only analysis with isolated review staging and reversible manifests.
- **Cloud-Aware Protection:** Win32 kernel-level reparse point detection that prevents unintended OneDrive / iCloud file downloads.
- **Header-Hasher Duplicate Detection:** 3-phase cryptographic byte verification to identify true file duplicates regardless of filename.
- **Inspectable Native Robocopy Scripts:** Standalone `.bat` scripts with restartable `/Z` flags for USB and external disk archiving.
- **100% Local & Zero Telemetry:** Local loopback service; no filesystem metadata ever leaves the machine.

## 🛠️ Tech Stack

- **HTML5 & Vanilla CSS:** High-performance glassmorphism, responsive grid architecture, and CSS custom property design system.
- **Vanilla JavaScript:** Zero-dependency interactive live disk scanner simulation, interactive manifest inspector, and dynamic animations.
- **Typography:** Plus Jakarta Sans & JetBrains Mono via Google Fonts.
